# წიგნიერი — ქართული ონლაინ წიგნების მაღაზია

**სასწავლო / საგამოცდო პროექტი (MVP)**

Django 6.1.3 · Python · SQLite · HTML · CSS

## პროექტის შესახებ

„წიგნიერი“ არის ქართული ონლაინ წიგნების მაღაზიის ვებაპლიკაცია, რომელიც მომხმარებლებს საშუალებას აძლევს დაათვალიერონ წიგნების კატალოგი, მოძებნონ სასურველი გამოცემები, დაამატონ წიგნები კალათაში და გააფორმონ შეკვეთები.

## ძირითადი ფუნქციონალი

- მომხმარებლის რეგისტრაცია და ავტორიზაცია;
- წიგნების კატალოგის დათვალიერება;
- წიგნების ძიება და კატეგორიების მიხედვით გაფილტვრა;
- წიგნის დეტალური ინფორმაციის ნახვა;
- კალათაში წიგნების დამატება და რაოდენობის ცვლილება;
- კალათიდან წიგნების წაშლა;
- შეკვეთის გაფორმება;
- ციფრული წიგნების შეძენა და წვდომა;
- ფიზიკური წიგნების შეკვეთა;
- მომხმარებლის პროფილი და შეკვეთების ისტორია;
- ადმინისტრაციული პანელი მონაცემების სამართავად.

- Python

## პროექტის გაშვება — Windows 10

გახსენით პროექტის საქაღალდე VS Code-ში და ტერმინალში შეასრულეთ:

```cmd
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

შემდეგ გახსენით ბრაუზერში:

- მთავარი გვერდი: http://127.0.0.1:8000/
- წიგნების კატალოგი: http://127.0.0.1:8000/books/
- ადმინისტრირება: http://127.0.0.1:8000/admin/

## პროექტის სტრუქტურა

- `config/` — Django-ს კონფიგურაცია და ძირითადი მისამართები;
- `books/models.py` — მონაცემთა მოდელები;
- `books/views.py` — გვერდების დამუშავება და ბიზნესლოგიკა;
- `books/forms.py` — ფორმები;
- `books/templates/` — HTML შაბლონები;
- `books/static/books/style.css` — დიზაინი;
- `manage.py` — Django-ს მართვის ფაილი.

## მნიშვნელოვანი შენიშვნა

პროექტი შექმნილია სასწავლო და საგამოცდო მიზნებისთვის. რეალურ კომერციულ გარემოში გამოსაყენებლად საჭიროა უსაფრთხოების დამატებითი კონფიგურაცია, რეალური გადახდის სისტემის ინტეგრაცია და წარმოებისთვის შესაბამისი სერვერული გარემო.
