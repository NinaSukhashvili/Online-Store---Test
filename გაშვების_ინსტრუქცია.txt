წიგნიერი — გაშვება Windows-ზე

1. ამოარქივე მთლიანი wignieri3 საქაღალდე Desktop-ზე ან Documents-ში.
2. გახსენი wignieri3 საქაღალდე.
3. ორჯერ დააჭირე START_PROJECT.bat ფაილს.
4. პირველად გაშვებისას საჭიროა ინტერნეტი, რადგან Python პაკეტები ავტომატურად დაინსტალირდება.
5. ტერმინალის ფანჯარა არ დახურო. ბრაუზერში გახსენი http://127.0.0.1:8000/
6. საიტის გასაჩერებლად ტერმინალში დააჭირე Ctrl+C.

პროექტში შენარჩუნებულია არსებული db.sqlite3 და media ფაილები. არ წაშალო ისინი, თუ გინდა არსებული მომხმარებლები, წიგნები და ატვირთული PDF-ები შენარჩუნდეს.

გადახდა მხოლოდ სასწავლო სიმულაციაა; რეალურ ბანკთან დაკავშირებული არ არის და თანხას არ ჩამოაჭრის. სატესტო ფორმა იღებს ნებისმიერ 16 ციფრს. რეალური ბარათის მონაცემები არ შეიყვანო.

თუ START_PROJECT.bat არ გაეშვა, დააინსტალირე Python 3.12 ან უფრო ახალი ვერსია და ინსტალაციისას მონიშნე Add Python to PATH.
